🔍 Payment Flow Diagram

User Cart Page ↓ (Click "Proceed to Checkout") POST /checkout (with cart items) ↓ Backend Creates OrderHistory + OrderItems ↓ Setup Midtrans Config (server_key, is_production) ↓ Generate Snap Token via Midtrans API ↓ Return JSON: {snap_token, order_id, total} ↓ Frontend showPaymentModal(snapToken) ↓ (User selects payment method) triggerMidtransPayment(snapToken, 'qris' or 'bca_va') ↓ window.snap.pay(snapToken, config) ↓ (Midtrans Payment Page) User Pays (QRIS Scan / BCA Transfer) ↓ (Payment Success) onSuccess callback → Clear cart + Redirect shop

🎓 Key Code Examples

Backend: Generate Snap Token

// Setup Midtrans Config MidtransConfig::$serverKey = config('midtrans.server_key'); MidtransConfig::$isProduction = config('midtrans.is_production'); // Create Transaction $transaction = [ 'transaction_details' => [ 'order_id' => $orderId, 'gross_amount' => $total ], 'enabled_payments' => ['qris', 'bca_va'] ]; // Get Snap Token $snapToken = Snap::getSnapToken($transaction); return response()->json(['snap_token' => $snapToken]);

Frontend: Show Payment Modal

window.showPaymentModal = function(snapToken, orderId, total) { // Create modal element const modal = document.createElement('div'); modal.innerHTML = ` <h3>Pilih Metode Pembayaran</h3> <button onclick="triggerMidtransPayment('${snapToken}', 'qris')"> Bayar dengan QRIS </button> <button onclick="triggerMidtransPayment('${snapToken}', 'bca_va')"> Transfer BCA Virtual Account </button> `; document.body.appendChild(modal); }; window.triggerMidtransPayment = function(snapToken, method) { snap.pay(snapToken, { onSuccess: function(result) { // Clear cart & redirect localStorage.removeItem('customer_cart'); window.location.href = '/shop'; } }); };

🐛 Debugging & Troubleshooting

1. Check Midtrans Script Loaded

// Open browser console (F12) console.log(typeof snap); // Should return 'object'

2. Check Network Request

Browser DevTools → Network tab → Filter "checkout" → Check response contains snap_token

3. Console Logs

Payment flow logs ada di browser console dengan prefix:

  • [SUCCESS] - Payment berhasil
  • [PENDING] - Payment pending/menunggu konfirmasi
  • [ERROR] - Payment gagal
  • [INFO] - Modal closed by user

4. Common Issues

  • Modal tidak muncul: Check snap_token returned from /checkout
  • "Midtrans library tidak siap": Ensure Snap script loaded sebelum cart script
  • Snap token invalid: Verify MIDTRANS_SERVER_KEY & CLIENT_KEY di .env
  • Payment stuck: Check browser console untuk error message
